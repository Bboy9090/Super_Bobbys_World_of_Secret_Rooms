# Product Lineage Boundary

## What this repository actually is

This repository is a legacy technical/device platform lineage. Its current source tree contains:

- device analysis and USB enumeration,
- ownership/legal classification services,
- audit logging,
- Phoenix Key / BootForge integration,
- Bobby's Workshop Secret Rooms / Trapdoor administration,
- React/Tauri and Rust/Python service code.

The phrase **Secret Rooms** in this repository refers to privileged technical workspaces. It is **not** evidence of a puzzle/adventure game implementation.

## What this repository is not

Do not rename or market this source tree as:

**Bobby's House of Hidden Doors**

That approved entertainment identity is a separate puzzle/adventure IP and requires its own game code lineage, assets, save model, level/room architecture, store identity, and release qualification.

## Preservation rule

Until a deliberate technical consolidation says otherwise:

- computer recovery belongs to **Boot It Back**,
- recovery media belongs to **Phoenix Key**,
- phone/tablet work belongs to **BobFWTools**,
- BootForge remains an internal engine,
- historical Secret Rooms/Trapdoor code remains technical lineage only.

Do not migrate privileged device-operation APIs into an entertainment game.

## House of Hidden Doors product contract

When its dedicated implementation exists, the entertainment product should use:

- Public name: **Bobby's House of Hidden Doors**
- Tagline: **Every room is hiding something.**
- Genre: puzzle / exploration / adventure
- Core systems: hidden passages, keys/locks, impossible rooms, moving walls, layered secrets, story rooms, puzzle state, collectibles, room progression
- Icon: impossible illuminated doorway inside a house silhouette
- Splash: ordinary house unfolding into impossible hidden architecture

No current runtime, package, API, or security claim in this technical repository transfers automatically to that game.
