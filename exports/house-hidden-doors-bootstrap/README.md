# Bobby's House of Hidden Doors — Portable Bootstrap

This directory is intentionally self-contained. It does not import any device-repair, ownership-verification, compliance, audit, or authority-routing code from the parent repository.

Its purpose is to bootstrap the dedicated entertainment repository when repository creation is available.

Public title: **Bobby's House of Hidden Doors**

Tagline: **Every room is hiding something.**

Core loop:
1. enter a room
2. inspect interactables
3. satisfy clue/puzzle conditions
4. reveal or unlock a hidden door
5. traverse into the next room
6. record discovered secrets
7. unlock deeper wings

Initial wings:
- Ground Floor
- Basement
- Attic
- Workshop
- After Dark
- The Impossible Wing

Engine contracts included here:
- deterministic room/door graph
- immutable puzzle-state transitions
- inventory/key requirements
- one-way / locked / revealed door states
- regression tests

No runtime integration with the parent compliance product is permitted.
